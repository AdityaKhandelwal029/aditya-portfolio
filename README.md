# Aditya Khandelwal — Portfolio

Personal portfolio of **Aditya Khandelwal**, Software Engineer and Siemens Teamcenter developer (ITK · RAC · BMIDE · Workflows).

**Live site:** https://aditya-khandelwal-mu.vercel.app
**Resume (PDF):** https://aditya-khandelwal-mu.vercel.app/resume.pdf

## What's inside

- `index.html` — the whole site: a password screen (`Aditya`), then an 8-slide auto-playing portfolio with animated transitions, a node-network background and a "skills rain" that follows the cursor
- `aditya-photo.jpg` — profile photo
- `resume.pdf` — resume, linked from the site

Plain HTML, CSS and JavaScript with no build step. Fonts come from Google Fonts.

## Run locally

Open `index.html` in any browser.
